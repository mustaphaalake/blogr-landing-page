# Blogr Landing Page - Web Design Assignment

This is a responsive landing page for the Blogr brand, completed as a web design assignment submission.

## Project Description
The goal of this project was to build a modern, clean, and fully responsive landing page based on a design brief. It adapts seamlessly to various screen sizes, ensuring an optimal user experience on both mobile and desktop devices.

## Technologies Used
* HTML5: For structured and semantic web content.
* CSS3: For styling, layout design, and responsive media queries.
* JavaScript: For adding dynamic interactivity to the page.

## How to View the Project
1. Open the index.html file in any modern web browser.
